#
# Format :
#   ## id | Nom | Région | synonymes séparés par des virgules
#   > hypothèse affichée à l'utilisateur
#   - Libellé = Nom exact dans la base : grammes [opt] [#groupe]
#     (« Libellé = » est facultatif ; « opt » = ingrédient facultatif décoché par défaut ;
#      #fat = matière grasse de cuisson, #parts = parties au choix, #side = accompagnement)
# Les grammes sont ceux d'une portion habituelle, ingrédients cuits (sauf mention).
